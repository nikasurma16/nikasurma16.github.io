# nika-sur-ma.github.io

Портфолио: купольное кино, видеомэппинг, AR, многоканальный звук.
Статический сайт, двуязычный (RU/EN), без зависимостей и без сборщиков.

## Что где

```
build.py              весь текст сайта + генератор страниц
index.html            слайд-дек (генерируется)
about.html            био и CV (генерируется)
work/*.html           страницы проектов (генерируются)
assets/css/site.css   стили
assets/js/site.js     дек, пагинация, переключатель языка, появление вырезок
assets/js/bg.js       фоновое видео + смещение кадров под курсором (WebGL2)
assets/img/           изображения
assets/video/         фоновые лупы
tools/                скрипты пересборки фонов
```

**HTML-файлы редактировать не нужно** — они перезаписываются. Весь текст
живёт в `build.py`, в списках `WORKS`, `CV`, `BIO_EN`, `BIO_RU`.

## Пересобрать

```bash
python build.py
```

Ничего ставить не надо — только Python 3.

## Посмотреть локально

```bash
python -m http.server 8899
```

Затем открыть http://127.0.0.1:8899

## Добавить проект

1. Положить картинки в `assets/img/`.
2. Добавить словарь в список `WORKS` в `build.py` (проще всего скопировать
   соседний и заменить поля). `fit: "contain"` — для квадратных купольных
   кадров, `fit: "cover"` — для обычных фотографий.
3. `python build.py`.

## Контакты

В `build.py` вверху есть `EMAIL` и `TELEGRAM` — они пустые. Заполнить и
пересобрать, тогда адрес появится в подвале и на странице «обо мне».

## Вырезки

Документация работ выведена бумажными вырезками в духе Терри Гиллиама:
светлое поле под фотографией, неровный «резаный» край, жёсткая тень и
пружина в момент появления. Всё это класс `.cut` в `site.css`.

- Все фотографии переведены в чб (`.cut img { filter: grayscale(1) }`), чтобы
  коллаж читался как один вырезанный мир.
- Приземлившись, вырезка продолжает качаться на «петле» — анимация `cut-rock`
  с `steps(3)`, а не с плавным easing: вырезная анимация снимается покадрово.
  Ступенчатость заодно делает эффект дешёвым — элемент перерисовывается
  только в момент скачка, около трёх раз в секунду, а не 60. Наведение
  ускоряет качание.
- Угол наклона и форма края задаются в `build.py`, функция `cut()`:
  список `TILTS` и пять полигонов `.cut[data-shape="1..5"]` в CSS.
  Углы зафиксированы, а не случайны, чтобы страница не прыгала между сборками.
- Купольные кадры (`data-fit="contain"`) уже вырезаны по кругу в самих файлах,
  поэтому бумажной подложки под ними нет — только тень и пружина.
- Появление считается по координатам на таймере, а не через
  IntersectionObserver и `requestAnimationFrame`: встроенные и фоновые вкладки
  умеют останавливать цикл отрисовки, и тогда вырезка не появилась бы вовсе.
  По той же причине в состоянии покоя ничего не спрятано — анимация только
  добавляет пружину.

## Фон

По умолчанию — размытый портретный клип вверх ногами,
`assets/video/portrait.*`. У части работ свой фон:

| страница | фон |
|---|---|
| synesthetic r(AI)n | `rain` — документация мэппинга, вверх ногами |
| The Cage of DOME | `cage` — анимация проекта, вверх ногами |
| Волшебный фонарь | `lantern` — два кадра с «Ночи света», чб |
| Башня из слоновой кости | `ivory` — съёмка лаборатории, чб |

Зерно на фон добавляется не в файл, а в шейдер: ключ `"grain"` в словаре
работы (например `0.1` у Cage of DOME) уходит в `data-grain` на видео,
оттуда — в `bg.js`. Так оно не стоит ни байта битрейта и дрожит каждый кадр,
как настоящее зерно.

Рядом лежит ещё один фон, `assets/video/smoke.*` —
рендер из TouchDesigner-патча «Smoke and Liquid Displacement Effects»
(нода `/project1/comp4`), бесшовный луп на 12 секунд. Он сейчас нигде не
подключён, но остаётся в репозитории: чтобы вернуть, поменяйте значение по
умолчанию `bg="portrait"` на `bg="smoke"` в `head()` в `build.py`.

Видео и есть картинка; WebGL сверху ничего не рисует заново, а только смещает
эти же кадры под курсором — то самое liquid displacement, только от мыши.

Настройки в `assets/js/bg.js`: `WARP = 0` полностью выключает интерактивное
смещение и оставляет чистый луп, `STRENGTH` меняет, насколько сильно курсор
тянет изображение. Плотность фона — в `site.css`: `--bg-opacity` и
затемняющая плёнка `#veil` (на деке она слабее, на внутренних страницах
плотнее, чтобы текст читался). Без WebGL2 просто играет `<video>`, при
`prefers-reduced-motion` остаётся неподвижный постер.

### Пересобрать фон из TouchDesigner

`tools/render_background.py` разбирает `.toe` через `toeexpand`, вписывает в
него Execute DAT, который сохраняет кадры `comp4` и закрывает TouchDesigner,
и собирает обратно через `toecollapse`. Правьте вверху скрипта `SRC` (путь к
проекту) и `N_FRAMES`, затем:

```bash
python tools/render_background.py
```

Запустить получившийся `render/smoke_render.toe` в TouchDesigner — он сам
отрендерит кадры и закроется. Затем:

```bash
python tools/make_loop.py
```

Скрипт делает бесшовный луп (кроссфейд последних 2 секунд с началом) и
кодирует mp4/webm/постер прямо в `assets/video/`.

### Пересобрать портретный фон

```bash
python tools/make_about_loop.py "путь\к\клипу.mp4"
```

Скрипт апскейлит до 1440×1440 (lanczos), переворачивает вверх ногами
(`ROTATE`), размывает (`SIGMA`) и склеивает бумеранг — прямой проход плюс
обратный, — потому что исходник уходит от светлого к тёмному и обычный луп
дал бы скачок на стыке.

### Свой фон для отдельной работы

У страницы проекта может быть собственный фон — например, у мэппинга это
документация самой проекции. Нарезать луп из длинного исходника:

```bash
python tools/make_page_loop.py "исходник.mp4" rain 96 16
```

Аргументы: файл, имя фона, секунда начала, длина лупа. Флаги: `--gray` —
чёрно-белый, `--upright` — не переворачивать (по умолчанию ролик ставится
вверх ногами). Луп открывается кроссфейдом собственного хвоста с началом,
поэтому повтор не виден.

Если фон нужно собрать из фотографий, а не из видео:

```bash
python tools/make_stills_loop.py lantern фото1.jpg фото2.jpg
```

Кадры переводятся в чб и перетекают друг в друга по косинусу, так что
последовательность возвращается ровно в начало.

Дальше добавить в нужный словарь `WORKS` строку `"bg": "rain"` и, если нужно,
свою плотность плёнки в `site.css` по классу `body.bg-rain` (он проставляется
автоматически из значения `bg`).

`build.py` сам подставляет только те кодировки, которые реально лежат в
`assets/video/`, и ставит меньшую первой: VP9 не всегда выигрывает у H.264 —
на шумной ночной съёмке webm вышел в полтора раза тяжелее mp4 и был удалён.

## Публикация на GitHub Pages

Репозиторий должен называться `nika-sur-ma.github.io` и лежать в аккаунте
`nika-sur-ma` — тогда сайт открывается на https://nika-sur-ma.github.io

```bash
git remote add origin https://github.com/nika-sur-ma/nika-sur-ma.github.io.git
git push -u origin main
```

Затем в настройках репозитория: Settings → Pages → Source: `Deploy from a
branch`, ветка `main`, папка `/ (root)`.
